# Glossary

- Scroll-driven animation: scene state derives from scroll position and can reverse.
- Scrub: animation progress synchronized to scrolling.
- Pin: temporarily holds a section during scroll sequence.
- GLB/glTF: common real-time 3D asset formats.
- Fallback: simpler useful experience when primary feature is unavailable.
- Reduced motion: user preference for less animation.
- Scene controller: owns rendering, camera, assets, resize and scroll synchronization.
- Truth policy: unknown product/company facts are never fabricated.
- Vertical slice: complete feature implemented and verified end-to-end.
