# Open Questions / Inputs

## Brand
- Official company name/logo/tagline
- Approved tone, colors, fonts and languages
- Is Persian/RTL required?

## Products
- Categories and publishable models
- Verified specifications/units
- Photos, GLB/glTF models, brochures and licenses
- Approved claims

## Support
- Approved email or API endpoint
- Routing categories, required fields, retention policy
- Need for attachments and spam protection
- Approved phone/address

## Infrastructure
- Workspace root and existing stack
- Deployment host/domain/HTTPS
- Backend/API availability
- Analytics (default: none)
- Agent access to terminal/browser/files

## Character/creative
- Character model/illustration and rig
- Independent eye/eyelid controls
- Main machine model for narrative
- Licensing constraints for fonts, HDRIs, textures, stock assets

Proceed with reversible placeholders where safe; never invent answers.
