# Release Checklist

- [ ] Brand and company data approved.
- [ ] Product specs verified; placeholders not shown as facts.
- [ ] Contact details and CTA destinations verified.
- [ ] No copied/unlicensed assets.
- [ ] Install/start/build verified.
- [ ] Lint/typecheck/tests actually run and results recorded.
- [ ] No critical console errors/dead controls.
- [ ] Scroll works forward/backward.
- [ ] Missing model/WebGL fallback verified.
- [ ] Character event behavior verified where rig supports it.
- [ ] Support does not fake success.
- [ ] Mobile and reduced-motion QA complete.
- [ ] No committed secrets; `.env.example` is safe.
- [ ] Asset sizes/licenses reviewed.
- [ ] README, known limitations, missing inputs and deployment notes updated.
