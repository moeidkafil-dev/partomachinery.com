# Technical Decision Records

Create actual entries for:
1. Framework/build system — preserve working stack unless justified.
2. 3D approach — Three.js, React Three Fiber, or fallback; define render-loop owner.
3. Scroll system — progress normalization, reverse behavior, resize, cleanup, reduced motion.
4. Media strategy — real-time 3D, image sequence, hybrid, or static fallback; decide from actual assets.
5. Character asset — eye/eyelid rig capabilities, source/license, fallback.
6. Support endpoint — validation, abuse controls, privacy, data retention, failure mode.
7. Routing/localization — routes vs sections, RTL/language plan.
8. Quality adaptation — pixel ratio, model/texture tiers, measurements.

For each: context, options, choice, rationale, trade-offs, verification, and revisit condition. Never mark a provisional decision as user-approved.
