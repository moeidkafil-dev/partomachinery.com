# Scene Chapter Blueprint

| Chapter | Purpose | Possible visual role | Content |
|---|---|---|---|
| C0 Arrival | Identity/subject | Hero silhouette and controlled light | Proposition, primary CTA |
| C1 Reveal | Establish product form | Camera reveals recognizable geometry | Concise context |
| C2 Detail | Explain a verified feature | Focus on real machine detail | Verified feature copy |
| C3 Capability | Relate machine to process | Environment/material transition | Verified applications |
| C4 Portfolio | Product discovery | Category/portfolio composition | Category navigation |
| C5 Engineering | Build confidence | Calmer stable composition | Verified company/service facts |
| C6 Action | Make next step obvious | Stable readable end state | Inquiry/support |

For each implemented chapter record progress range, camera/target, object transforms, environment, DOM visibility, easing, responsive/reduced-motion/fallback variants and asset dependencies. Test reverse scroll at each boundary. Avoid dead zones unless deliberate and meaningful.
