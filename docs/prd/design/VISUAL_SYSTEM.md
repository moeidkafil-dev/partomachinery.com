# Visual System

Direction: industrial cinematic, engineered precision, deep atmosphere, tactile materials, intentional negative space, controlled accent color. Initial tokens: `#000F08` and `#FB3640`; test contrast and define neutral/surface/semantic tokens.

Define spacing, grid, content width, typography, fluid type limits, z-index, easing, duration bands, button variants, nav, product spec rows, category selector, FAQ, support fields/errors, loading states and viewer controls.

Use semantic DOM for essential text. Do not let canvas intercept clicks on links/forms. Avoid generic SaaS cards, gratuitous gradients/glassmorphism, constant parallax, and excessive animation. Ensure text remains readable over changing backgrounds and content density is adequate for technical buyers.
