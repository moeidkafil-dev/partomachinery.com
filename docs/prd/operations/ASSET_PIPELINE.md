# Asset Pipeline

Track asset ID, filename, purpose, source/owner, license, dimensions/format, size, optimization, responsive variants, fallback and verification status.

Prefer GLB/glTF for real-time models. Inspect scale/orientation, geometry, materials, texture dimensions/formats, animation/rig, transparency, license, download size and memory cost. Never assume models exist. Keep asset paths configurable and provide poster/static fallback.

If image sequence is chosen: consistent dimensions/aspect ratio, compressed frames, progressive loading, reverse scrubbing, request failure handling, poster fallback, mobile network and memory tests.

Do not copy Organimo assets, logos, text, or proprietary models. Keep font/image licenses and attribution notes. QA framing, textures, transparency, aliasing, size, mobile fallback and semantic alternatives.
