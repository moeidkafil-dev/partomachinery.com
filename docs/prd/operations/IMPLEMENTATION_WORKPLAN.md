# Implementation Workplan

0. Recon: inspect workspace, stack, scripts, assets; preserve work; read all docs.
1. Runnable foundation: app entry, layout, tokens, content contracts, fallback; run baseline checks.
2. Static composition: navigation, sections, product data, specs, FAQ, contact; verify without WebGL.
3. Scene proof: implement one full scroll-driven slice; verify reverse, resize, cleanup, fallback.
4. Full narrative: add chapters/transitions, responsive and reduced-motion behavior.
5. Product viewer: integrate supplied assets or adapter/fallback; preserve specs.
6. Character: gaze, independent blinks, scoped context menu, keyboard/touch.
7. Support: accessible panel, validation, real endpoint only if supplied; otherwise honest unconfigured state.
8. QA: build/lint/typecheck/tests, desktop/mobile/reduced motion, console/link checks, measure asset sizes.
9. Handoff: README, `.env.example`, asset requirements, actual results and limitations.

This is a sequence of quality gates, not permission to stop after planning.
