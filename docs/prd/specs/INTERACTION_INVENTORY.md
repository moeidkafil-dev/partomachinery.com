# Interaction Inventory

|---|---|---|---|
| Nav link | Click/tap | Route/section | Enter, valid href |
| Primary CTA | Click/tap | Real next step | Keyboard action |
| Scene | Scroll | Narrative progress | DOM content |
| Product category | Click/tap | Update selection | Button + selected state |
| Viewer | Drag | Rotate model | Static poster/specs |
| Reset view | Click/tap | Restore camera | Omit if unsupported |
| Character | Pointer move | Eye tracking | Neutral gaze |
| Character left click | Left click | Left blink | Rig-aware fallback |
| Character right click | Right click | Right blink; scoped menu suppression | Native menu elsewhere |
| Support control | Click/tap | Open panel | Enter/Space |
| FAQ | Click/tap | Expand/collapse | Semantic button |
| Support submit | Submit | Validate/API request | Honest unconfigured state |
| Panel close | Click/Escape | Close/restore focus | Safe state transition |
| Mobile menu | Tap | Open/close nav | Keyboard/Escape |
